# CrewAI Generated Crew

Ce projet est destiné à créer des équipes générées par IA en utilisant les technologies OpenAI et Gemini, déployées dans un conteneur Docker.

## Stack Utilisée
- OpenAI
- Gemini
- Docker

## Comment exécuter le projet
Pour exécuter ce projet, veuillez suivre les instructions suivantes:
1. Cloner le dépôt.
2. Construire l'image Docker:
   ```bash
   docker build -t crewai-generated .
   ```
3. Exécuter le conteneur:
   ```bash
   docker run -it crewai-generated
   ```
